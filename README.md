# telegram_sender

Рассылает пост (photo.jpg + подпись) во все каналы из targets.txt (интервал SEND_INTERVAL сек, порядок случайный): один раз сразу при деплое, дальше по расписанию (ofelia в docker-compose.yml).

## Кэшбек из гугл-таблицы

Процент кэшбека подтягивается перед каждой рассылкой из гугл-таблицы продавца
(той же, что подключена к axiomai): первый лист, колонка C — процент, колонка F — артикул.
Поменяли процент в таблице — следующая рассылка уйдёт уже с новым процентом и пересчитанными суммами.

Настройки в config.py:
 - `CASHBACK_TABLE_ID` — ид таблицы (из ссылки docs.google.com/spreadsheets/d/<ид>/edit)
 - `CASHBACK_NM_IDS` — артикулы раздачи, процент берётся по первому найденному в таблице
 - `WB_PRICE` — цена на ВБ для расчёта сумм в посте
 - `FALLBACK_CASHBACK_PERCENT` — резервный процент, если таблица недоступна

Источник процента (таблица или резерв) виден в отчёте о рассылке в REPORT_CHAT.

## Файлы на сервере (в git не попадают)

 - `.env` — API_ID, API_HASH
 - `service_account.json` — ключ сервисного аккаунта Google, у которого есть доступ к таблице
 - `sender_session.session` — сессия Telegram

## При смене артикула на раздачу изменить

 - photo.jpg
 - config.py: CASHBACK_NM_IDS, WB_PRICE, CAPTION_TEMPLATE
